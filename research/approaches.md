## Что из этого уже было у нас
- DMC в стиле DouZero (v1–v4), лига прошлых версий, примесь эвристических соперников (как «игра против прошлой реплики»).
- PIMC (как GIB/BEN/Kermit) с точным max^n в эндшпиле; сэмплирование раскладов с учётом пустот и заказов (упрощённый
  «table-based» инференс Kermit).
- Раздельные модели заказа и розыгрыша (как BEN: торговля сетью отдельно).

## Что добавлено в этой итерации (правила компании)
1. **Вспомогательная голова «где лежат карты»** (идея PerfectDou/Suphx в дешёвом варианте + CLI Солинаса): при обучении
   DMC сеть дополнительно предсказывает, у кого из соперников каждая невидимая карта (правду знает тренер). На игре голова
   не используется — она только улучшает представление. Сравнение A/B: `house_A` (без) vs `house_B` (aux 0.3).
2. **Policy-based inference для PIMC** (Rebstock et al.): веса сэмплированных раскладов ∝ Π P_сеть(наблюдённый ход
   соперника | его гипотетическая рука) — см. `agents/pimc.py` (`infer="policy"`).
3. Дообучение под новые правила с warm start от лучшей сети прошлых правил (перенос знаний; смена правил — частный случай
   curriculum).

## Что сознательно не делаем (и почему)
- ReBeL/SoG: для 4 игроков с общей суммой ≠ 0 теоретические гарантии не действуют, а вычислительно это на порядки дороже.
- Полноценный PPO с oracle-критиком (PerfectDou): требует переписать тренер; aux-голова даёт часть эффекта (лучшее
  представление скрытого состояния) за ~20 строк кода.
- ISMCTS: в Яссе он уступил детерминизированному поиску, у нас уже есть PIMC.

## Дополнение: лучшие подходы для игр с неполной информацией (поиск 2026-11-08)

| подход | суть | применимость к нам |
|---|---|---|
| **SPARTA** (Lerer et al., Hanabi) https://arxiv.org/abs/1912.02318 | Монте-Карло-поиск поверх готовой «blueprint»-политики по точному распределению скрытых карт; доказано «не хуже blueprint» с точностью до шума роллаутов; Hanabi 24.61/25 | наш PIMC с NN-роллаутами — та же схема; выигрыша не дал (−0.45 [−1.07, +0.18]): в 4-игровой игре с конкуренцией «blueprint»-модель соперников неточна |
| **Learned Belief Search** (Hu, Lerer, Brown, Foerster 2021) https://arxiv.org/abs/2106.09086 | вместо точного перебора — обученная модель распределения скрытых карт (авторегрессионная), 55–91% выгоды SPARTA при 5–36× меньших вычислениях | следующий шаг: обучить модель «у кого какие карты» по истории (данные бесплатные из self-play) и сэмплировать из неё в PIMC |
| **DeepNash / R-NaD** (DeepMind, Stratego) https://arxiv.org/abs/2206.15378 | model-free self-play, регуляризованная динамика сходится к ε-Нэшу вместо циклов | для 2-игровых игр с нулевой суммой; у нас 4 игрока и не нулевая сумма — гарантий нет, но регуляризация к прошлой политике может стабилизировать self-play |
| **DouZero / PerfectDou** https://arxiv.org/abs/2106.06135 | история ходов кодируется **LSTM** и конкатенируется с остальными признаками; PerfectDou — критик с полной информацией | история добавлена (по-взяточное one-hot кодирование, 8×160 признаков; LSTM/attention — следующий шаг) |
| **DouRD** (2026) | attention для истории помогает «угадывающим» ролям, LSTM — для долгого планирования | |
| **Generative MCTS для взяточных игр** https://arxiv.org/pdf/2404.13150 | генеративная модель для сэмплирования скрытых состояний вместо детерминизаций | близко к LBS |
| **Outer-Learning, Skat** (2025) https://arxiv.org/pdf/2512.15435 | многопользовательская взяточная игра; внешний цикл обучения поверх поиска | |
| **Valet** (2026) https://arxiv.org/pdf/2603.03252 | бенчмарк 21 традиционной карточной игры с неполной информацией | для сравнения методов |
| **NooK** (NukkAI, бридж 2022) | гибрид нейросети + символьного вывода; обыграл 8 чемпионов в розыгрыше (без торговли) | |
| **«Читер» / oracle** (Suphx, PerfectDou) | агент с полной информацией как учитель и как оценка потолка | обучен у нас (`house_X`) — см. INSIGHTS H4 |
